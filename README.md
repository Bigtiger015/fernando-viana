# Prévia do site de Fernando Viana 5000

Duas propostas visuais para a campanha comparar e escolher.

Página de escolha: https://bigtiger015.github.io/fernando-viana/

| Versão | Link | O que é |
|---|---|---|
| 1 — Direta | https://bigtiger015.github.io/fernando-viana/versao-1/ | Cartaz limpo, foto inteira, sem animação. |
| 2 — Laboratório visual | https://bigtiger015.github.io/fernando-viana/versao-2/ | Recorte sobre composição gráfica, textura de tecido em vídeo, animações. |

Mesmo conteúdo e mesmas fotos nas duas; muda só o tratamento visual.

## Estrutura

Site estático no GitHub Pages, raiz da branch `main`.

- `index.html` — página de escolha
- `versao-1/`, `versao-2/` — cada uma é o site completo e navegável
- `assets/` — fotos, marca, fontes e vídeo, compartilhados pelas duas versões (referência `../assets/`)

As duas versões mantêm a identificação de prévia e `noindex, nofollow`.

Textura animada de tecido da versão 2 gerada por IA com Higgsfield.
