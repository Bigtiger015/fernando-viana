# Prévia do site de Fernando Viana 5000

Endereço da prévia: https://bigtiger015.github.io/fernando-viana/

A raiz é a **versão 2 (laboratório visual)**, escolhida pela campanha em 23/09/2026.
A versão 1 continua acessível em `versao-1/` para comparação; `versao-2/` redireciona para a raiz,
para os links já compartilhados continuarem valendo.

Prévia, não endereço oficial: páginas com `noindex, nofollow`. Antes do endereço oficial:
domínio próprio, hospedagem conforme a Res. TSE 23.610 e comunicação do endereço à Justiça Eleitoral.

## Estrutura
- `index.html`, `acessibilidade.html`, `imprensa.html`, `privacidade.html`, `styles.css`, `laboratorio.css`, `app.js`, `laboratorio.js`: versão 2
- `assets/`: fotos, marca, fontes e vídeo, compartilhados
- `versao-1/`: versão 1 (direta)
- `versao-2/`: redirecionamento para a raiz
